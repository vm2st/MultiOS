# MultiOS 0.8-dev: консольные расширения

**vm2 studios | t.me/v2vproj**. Неопубликованная разработка, не Release 1.0.

## Полноценная клавиатура и редактирование

Физические клавиатуры не отключены двухкнопочным режимом. USB/BIOS — см.
NATIVE_USB_RU.md; UEFI использует ввод прошивки. При открытой OSK стрелки управляют
панелью, Enter нажимает выделенную ячейку. Для обычного набора скройте её F2 или
Ctrl+O. F6/F7 снова открывают панель, необязательная F5 доступна при 3+ кнопках.

- Left/Right или Ctrl+B/F — перемещение курсора внутри строки.
- Home/End или Ctrl+A/E — начало/конец.
- Delete или Ctrl+D — удаление справа; Backspace — слева.
- Печатные символы вставляются в текущую позицию.
- F8/F9 или Ctrl+P/N — старее/новее в истории из восьми команд.
- При возврате из истории восстанавливается незавершённый черновик.
- `HISTORY` выводит историю; последовательные одинаковые команды не дублируются.
- Ctrl+C отменяет строку; Enter выполняет всю строку независимо от курсора.

Up сохранён для открытия скрытой OSK, а не истории. F8/F9 выбраны, чтобы не
ломать это поведение. Максимум строки — 511 ASCII-байт; если были потеряны
символы из-за переполнения, строка не исполняется. Unicode/русской раскладки нет.

В обычных PC-рендерерах добавлен переход Backspace на предыдущую экранную строку.
Длинные строки при прокрутке экрана не получили полноценного terminal model:
редактирование через границу scroll не сертифицировано. Serial terminal может
по-своему обрабатывать обратный переход; аппаратные стрелки декодируются
драйверами, ANSI escape-sequences из serial пока не разбираются.

PS/2: исправлены независимые L/R Shift, добавлены Right Ctrl, Num Lock/keypad,
keypad Enter/slash, Home/End/Delete; Pause sequence пропускается, не оставляя
ложный Ctrl/NumLock. Caps/Num не переключаются повторно от одинакового make-кода.
LED-команды физической клавиатуре по-прежнему не отправляются.

## MORE — страницы файла

```text
MORE /README.TXT
```

Пауза примерно через 12 текстовых строк/переносов. В паузе:

- **F6 / NEXT** или Space/Enter — следующая страница;
- **F7 / SELECT** или Q/Esc/Ctrl+C — закончить просмотр.

В этом контексте обе кнопки работают напрямую, без ввода букв из OSK. Положение
и Shift панели не меняются. Произвольный экран требует настройки своего renderer;
порог 12 строк выбран для готовых PC-рендереров, не является универсальным LCD API.

## SOURCE — собственные командные сценарии

```text
SOURCE /START.MOS
```

ASCII-текст, одна команда на строке. Пустые строки, ведущие пробелы, комментарии
с `#` или `;` в начале строки, LF и CRLF поддержаны. Пример содержимого:

```text
# vm2 studios | t.me/v2vproj
VER
CPU
USB
DIR /
ECHO Scenario complete
```

- До 4096 байт на сценарий, до 511 байт на строку, до 16 аргументов.
- Рекурсивный SOURCE ограничен глубиной 4.
- Сценарий заранее читается в память; ошибка символов отвергает весь вход до
  исполнения. При ошибке команды исполнение останавливается с номером строки.
- EXIT останавливает сценарий и shell.
- Это **не DOS BAT**, не COM/EXE, не язык с IF/GOTO/переменными/пайпами.
- Сценарий может менять файлы, если запись явно разблокирована. Выполняйте только
  доверенные сценарии на резервных копиях; sandbox/прав доступа нет.

## Диагностика

- `DEVICES` или `PCI`: native PCI inventory с bus/slot/function, vendor/device,
  class/subclass/interface; до 128 записей с указанием пропущенных.
- `USB`: native UHCI состояние, число клавиатур, reports, errors, disconnects.
- На host/UEFI native PCI-сканирование пока не выполняется: вывод прямо говорит
  «unavailable», не выдаёт искусственные устройства за найденные.

## Двухкнопочная работа

Базовая модель остаётся прежней: NEXT + SELECT, а при третьей кнопке ещё PREVIOUS.
Новая физическая клавиатура — дополнительный способ, а не новое обязательное
оборудование. Старые дву/трёхкнопочные тесты повторяются вместе с регрессией.
