# Инструкция по образу MultiOS / MultiPulti (схема с 0.12)

**vm2 studios | t.me/v2vproj**

**НЕОПУБЛИКОВАННАЯ РАЗРАБОТКА. Не Release 1.0.**

Первым откройте **START_HERE_RU.md**: запуск готового образа, команды консоли, редактирование файлов через обычную папку, ограничения реального железа.

## В поставке

- Один готовый редактируемый образ: `build/MultiOS-MultiPulti.img`, 128 МиБ, MBR + FAT32 ESP + FAT32 DATA.
- Собственное BIOS i386-ядро MultiPulti на C с минимальными ASM-загрузкой/входом/обработчиками. На x64 BIOS работает в 32-битном режиме.
- x64 UEFI-вариант использует сервисы прошивки; собственное post-UEFI x64-ядро ещё не готово.
- Полные исходники, профили статических драйверов, инструменты сборки/редактирования, тесты и свежие отчёты `build/unicode-*`.
- SHA256SUMS для проверки файлов. Тестовые дополнительные `.img` не распространяются; их создают тесты/сборка.

## Файловые системы

| ФС | Чтение | Запись |
| --- | --- | --- |
| FAT32 | Да, с ограничениями | Экспериментальная, по умолчанию выключена |
| exFAT | Да, с ограничениями | Экспериментальная, по умолчанию выключена |
| NTFS | Ограниченная RO-реализация собственного C backend | **Нет** |

Полноценную NTFS RW и стабильность FAT32 при отключении питания эта поставка **не обещает**. Актуальные ограничения — в `FILESYSTEMS_UNICODE_RU.md`; старые guides сохранены как история.

## Быстрое редактирование

```sh
cp build/MultiOS-MultiPulti.img my-system.img
python3 tools/studio.py unpack my-system.img MyMultiOS
# Меняйте MyMultiOS/files/ и при необходимости MyMultiOS/settings.ini
python3 tools/studio.py plan MyMultiOS
python3 tools/studio.py apply my-system.img MyMultiOS --backup before-edit.img --yes
```

Linux/WSL: Python 3 + mtools + dosfstools; ВМ должна быть остановлена. Не используйте физический диск. DATA пересоздаётся из files/, поэтому атрибуты/времена/алиасы 8.3 могут измениться. NTFS/exFAT этим редактором намеренно не пересоздаются.

Модули сейчас **статические**: меняйте C-реализацию/профиль, пересобирайте и заменяйте согласованные бинарники. Копирование `.c` или произвольного `.drv` в образ не добавляет драйвер. Открывайте `MODULAR_0_12_RU.md`.
