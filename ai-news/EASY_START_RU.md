# MultiOS 0.25-dev-easymod / MultiPulti — быстрый старт

**vm2 studios | t.me/v2vproj. UNPUBLISHED development, НЕ стабильный Release 1.0.**

## Готовые образы

Начните с `images/MultiOS-0.25-fat32.img`. Варианты `-ntfs.img` и `-exfat.img`
отличаются файловой системой DATA. Загрузочный раздел во всех случаях FAT32.
Это raw-диски, НЕ ISO и НЕ установщик Windows. Для USB используйте побайтовую
запись образа (например Rufus в режиме DD или balenaEtcher), тщательно проверив
выбранное устройство: **прежние разделы и данные флешки будут уничтожены**.
Сначала сделайте резервную копию. Затем безопасное извлечение и Boot Menu ПК.
Не форматируйте неизвестный раздел 0xDA: это защита транзакций. Не расширяйте и
не перемещайте разделы этой сборки. Загрузчик не подписан для Secure Boot:
нужна собственная доверенная подпись либо отключённый Secure Boot на вашем ПК.
Внутренний диск эта версия автоматически не переразбивает и установщика на него нет.

UEFI x64 использует прошивочный Block I/O; Boot Services остаются активными.
BIOS: i386+, минимум32 МиБ RAM, IDE primary master с проверкой boot MBR-ID.
**Загрузка BIOS с USB не означает поддержку USB-диска в ядре!** Native USB-storage,
AHCI/NVMe в BIOS пока нет. Для USB на современных ПК используйте UEFI, если
поддерживается прошивкой. В BIOS VM образ подключается первым IDE, не SATA.
Нет поддержки 8086/286, IA32 UEFI, GPT/4Kn и гарантии «все ПК».

## Настройка без компилятора

На внешнем компьютере нужен Python3.9+; для окна — Tkinter. Откройте
`editor/EDIT-WINDOWS.cmd`, `editor/EDIT-LINUX.sh` или выполните:

```sh
python3 editor/customize.py --gui
```

Выберите .img, параметры и «Сохранить НОВЫЙ образ». Закройте VM перед работой.
Редактор никогда не меняет исходный образ и не пишет на физические диски.
Linux может требовать python3-tk. Windows/macOS GUI в этой среде не тестировался.

`editor/SETTINGS.INI`:

```ini
osk=off
bios_input=auto
storage=guarded
```

- osk=on/off — экранная клавиатура при старте.
- bios_input=auto/ps2-only/usb-only — выбор имеющегося BIOS-ввода. auto: PS/2,
  COM1 и ограниченный Intel UHCI boot keyboard. ps2-only оставляет COM1,
  usb-only требует поддержанного UHCI. Это не добавляет xHCI/EHCI/хабы.
  UEFI-ввод предоставляется прошивкой и этим BIOS-параметром не меняется.
- storage=guarded — RO до явного unlock YES, экспериментальная запись.
- storage=readonly — принудительный RO-провайдер: unlock не разрешит запись.

```sh
python3 editor/customize.py images/MultiOS-0.25-fat32.img
python3 editor/customize.py images/MultiOS-0.25-fat32.img --preset two-buttons --output Mine.img
python3 editor/customize.py images/MultiOS-0.25-fat32.img --settings editor/SETTINGS.INI --output Mine.img
```

Профили: desktop, two-buttons, safe, ps2. Список: --list-presets.
Назначение должно быть новым файлом. Редактор откажет при обнаруженных ошибках
CRC/зеркал, FAT cross-link, нечистом/чужом журнале. Не обходите проверки стиранием
журнала: восстановите его в MultiOS либо используйте резервную копию.

В образе EASY/SETTINGS.INI — понятные настройки, MULTIOS/BOOT.CFG — профиль UEFI,
MULTIOS/BIOS.CFG — зеркало BIOS. BIOS читает CRC-копию в LBA16.
**Просто изменить INI на смонтированной флешке недостаточно**: сохраните его во
внешний файл и примените редактором к .img, который синхронизирует четыре места.
Редактор меняет только содержимое фиксированных config-файлов и BIOS-слота,
не форматирует, не аллоцирует FAT и не изменяет DATA. Для записанной флешки:
сначала скопируйте нужные данные, настройте .img, затем запишите заново.

## Ввод и консоль

Полная клавиатура работает через доступный провайдер. F2/Ctrl+O — OSK on/off.
F6 — следующий, F7 — выбрать; F5 — предыдущий при наличии третьей кнопки.
На своей плате аппаратные две кнопки нужно привязать к NEXT/SELECT в драйвере:
это не автоматический GPIO-драйвер. Стрелки/Enter тоже управляют OSK.
Включённая OSK трактует Enter как выбор виртуальной клавиши, не обычный ввод
строки: используйте виртуальный Enter либо выключите OSK. Есть Back/Space/Shift/Hide.

help — актуальный список команд. ver/modules/fs — версия/драйверы/ФС;
dir/cd/type — просмотр. unlock YES — экспериментальная запись на тестовых
данных, lock — возврат RO, exit — выход из оболочки. Не храните единственную
копию важных данных на экспериментальном образе.

## Исходники и драйверы

source/MultiOS-source.zip и source/MultiOS/ — все исходники и включённые
библиотеки с лицензиями. Такой же снимок в образе SOURCES/PORTING.ZIP.
Строить внутри MultiOS пока нельзя: нужен внешний toolchain.
MODULARITY_0_25_RU.md объясняет структуру и сборку. Новый C-драйвер требует
компиляции и проверки; замена настроек выбирает только уже собранные провайдеры.
Нет горячей загрузки .drv/ELF. GUI-редактор — внешняя программа, не графическая ОС.

## Ограничения стабильности

Сохраняются 512-byte MBR, бюджет до4096 изменённых секторов одной операции,
необходимость честного flush/read. CRC не криптозащита и не доказательство
сохранности при лживом кэше/записи не по адресу. NTFS-3G порт не равен полной
Windows-совместимости: нет гарантий ACL/SID/reparse/EFS/BitLocker/$LogFile recovery,
ntfsfix не заменяет chkdsk. При ошибке commit результат UNKNOWN (старый либо новый
целый результат). Эмуляция не заменяет реальное железо/отключение питания.
Release1.0 и публичная публикация не объявляются.
