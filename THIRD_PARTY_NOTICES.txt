The UEFI binary links GNU-EFI 3.0.11 runtime/library components.
Since 0.19 the default SDK is built from the included unmodified source archive
with explicit baseline x86-64 flags; see tools/build_uefi_runtime.py.
GNU-EFI source archive and per-file notices are included under third_party/gnu-efi.
Upstream: https://github.com/ncroxon/gnu-efi/tree/3.0.11
These components retain their own copyrights and licenses.
QEMU, OVMF firmware, compilers and formatting tools are NOT included.
Filesystem profiles differ:
- Legacy profiles retain vm2's original bounded FAT32/exFAT writers and NTFS reader.
- filesystems-fatfs.mk includes ChaN FatFs R0.16 patch 2 for FAT32/exFAT
  reads, directory enumeration, free-space queries and mutations (0.18+).
  Original notices retained in vendor/fatfs; configuration changes
  and wrappers are identified separately. Permissive upstream notice applies.
- filesystems-ntfs3g.mk additionally links NTFS-3G 2022.10.3 library code,
  GPL-2.0-or-later. Copyrights, AUTHORS, COPYING and COPYING.LIB retained in
  vendor/ntfs-3g. No FUSE or unix_io component is linked in the firmware.
  Combined NTFS-enabled binaries are distributed under GPL-2.0-or-later with
  corresponding buildable sources. This does not remove MIT permissions on
  separately identifiable original MultiOS components.
  NTFS-3G bridge files identify GPL-2.0-or-later explicitly.
- ports/ntfs3g uses host C headers for declarations when cross-compiling x64,
  but links no glibc, Linux kernel, FUSE, syscall layer or host shared library
  into BOOTX64.EFI. Runtime symbol audit and firmware tests are included.
- GNU-EFI components retain their original licenses as listed below.

Upstream provenance and file hashes: vendor/*/UPSTREAM.json.

Unicode filename case data: lib/unicode_upcase.h is the 874 non-identity
BMP pairs decoded from the pre-existing tools/upcase.bin recommended exFAT
upcase mapping. No host locale or Unicode library is linked. exFAT and NTFS
use their volume-specific tables instead. FAT32 uses this fixed BMP mapping
as a documented interoperability policy, not a claim about every OEM code page.
